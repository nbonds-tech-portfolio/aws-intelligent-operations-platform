An end-to-end cloud engineering project designed to demonstrate modern DevOps, MLOps, and AIOps practices on AWS.

The project evolves through structured phases covering:

Git and Source Control
Python Development Environments
Infrastructure as Code (Terraform)
Containerization (Docker)
Kubernetes (EKS)
CI/CD Pipelines (GitHub Actions)
Monitoring and Observability
Machine Learning Operations (MLflow, SageMaker)
Model Monitoring and Retraining
AIOps Concepts and Intelligent Automation
The goal is to build a production-style platform while developing practical skills applicable to DevOps Engineer, Cloud Engineer, MLOps Engineer, AI Platform Engineer, and Site Reliability Engineer (SRE) roles.
